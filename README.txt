# Danny Stores

A responsive e-commerce starter website for Zambia.

Included:
- Clothes carousel using the six uploaded product images
- Zambian Kwacha pricing
- Cart drawer
- Responsive mobile/desktop layout
- Contact details
- Checkout placeholder ready for a real payment gateway
- Basic SEO metadata

Payment gateways are NOT connected yet. Add merchant credentials only through a secure backend/server environment.

Deploy on Netlify by uploading this folder (or a ZIP) through Netlify Drop.
